Version 1 · Mobile

App Shield

Enthalten in jeder WEB-Shield-Lizenz (Abo, Team und Gratis-Test). Die Installation erfolgt vollständig auf dem Mobile.

AbsenderDEXXUS
BetreffIhre Lizenz App Shield und WEB Shield (L-2026-0123)
EnthältGrüne Schaltfläche «App Shield freischalten»
Auf dem Mobile
  1. 1
    E-Mail auf dem Mobile öffnen

    Öffnen Sie die E-Mail von DEXXUS in der Mail-App Ihres Mobiles.

  2. 2
    Freischalten

    Tippen Sie in der E-Mail auf die grüne Schaltfläche App Shield freischalten. App Shield öffnet sich und meldet «App Shield ist freigeschaltet».

  3. 3
    Installation starten

    Tippen Sie in App Shield oben im grünen Feld auf Installieren.

    Öffnet sich zuerst Chrome, tippen Sie dort erneut auf «Installieren». iPhone: Tippen Sie in Safari unten auf «Teilen» und wählen Sie «Zum Home-Bildschirm».

  4. 4
    Installation bestätigen

    Bestätigen Sie mit «Installieren» bzw. «Hinzufügen».

  5. 5
    Kontrolle

    Öffnen Sie App Shield von DEXXUS mit dem DX-Symbol auf dem Startbildschirm Ihres Mobiles. Fertig.

Installation abgeschlossen. Gratulation – Sie haben App Shield erfolgreich installiert.
Gratulation, Sie haben sich für Shield, den KI-Schutz, entschieden – das ist clever.
Bei Fragen wenden Sie sich bitte an den Support von DEXXUS: info@dexxus.ch
Version 2 · Browser am PC

WEB Shield

Für Microsoft Edge und Google Chrome. Gilt für WEB Shield Abo, Team 4, Team 10 und Gratis-Test. Es gibt zwei Wege – wählen Sie den Weg, über den Sie WEB Shield erhalten haben.

WEB Shield ist im Microsoft Edge Add-ons Store. Jetzt für Edge hinzufügen. Für Google Chrome ist die Erweiterung in Prüfung bei Google und folgt in Kürze. App Shield auf dem Mobile und PC Shield für Windows funktionieren sofort. Wer Chrome nutzt und jetzt kauft, erhält die Lizenz sofort und kann WEB Shield nach der Freigabe ohne Mehrkosten installieren.
Weg 1 Kauf über den Store Sie haben WEB Shield im Store von Microsoft oder Google gefunden.
  1. 1
    Im Store öffnen

    Edge: DEXXUS WEB Shield im Edge Add-ons Store öffnen oder dort nach «DEXXUS WEB Shield» suchen. Chrome: in Prüfung bei Google, folgt in Kürze.

  2. 2
    Erweiterung installieren

    Klicken Sie auf «Abrufen» (Edge) bzw. «Hinzufügen» (Chrome) und bestätigen Sie mit «Erweiterung hinzufügen».

  3. 3
    Symbol anheften

    Klicken Sie oben rechts neben der Adresszeile auf das Puzzle-Symbol und auf die Stecknadel neben «DEXXUS WEB Shield».

  4. 4
    Gratis-Test beginnt

    Öffnen Sie chatgpt.com und klicken Sie auf das blaue DX-Symbol. Der Gratis-Test über 30 Tage startet automatisch. Copilot: als Webseite öffnen (copilot.microsoft.com), nicht über den Copilot-Knopf oben rechts in Edge – dieser teilt sich die Seitenleiste mit WEB Shield und verschwindet.

  5. 5
    Abo kaufen

    Klicken Sie in WEB Shield auf Jetzt kaufen. Sie gelangen auf dexxus.ch, wählen Ihr Abo und bezahlen.

  6. 6
    Lizenz-E-Mail erhalten

    Nach der Zahlung erhalten Sie eine E-Mail von DEXXUS mit dem Betreff «Ihre Lizenz App Shield und WEB Shield (L-…)». Speichern Sie den Anhang L-….dxlic mit «Speichern unter» auf dem Desktop.

  7. 7
    Lizenz einlesen

    Klicken Sie in WEB Shield auf Lizenz erhalten? und ziehen Sie die Lizenzdatei vom Desktop in das Feld.

Weg 2 Kauf über die Webseite dexxus.ch Sie haben auf dexxus.ch bestellt oder einen Gratis-Test angefordert.
  1. 1
    Bestellen

    Wählen Sie auf dexxus.ch unter «Preise» Ihr WEB-Shield-Abo bzw. den Gratis-Test und schliessen Sie die Bestellung ab.

  2. 2
    Lizenz-E-Mail erhalten

    Sie erhalten eine E-Mail von DEXXUS mit dem Betreff «Ihre Lizenz App Shield und WEB Shield (L-…)». Öffnen Sie diese E-Mail am PC.

  3. 3
    Lizenzdatei speichern

    Klicken Sie mit der rechten Maustaste auf den Anhang L-….dxlic, wählen Sie «Speichern unter» und speichern Sie die Datei auf dem Desktop.

  4. 4
    Erweiterung installieren

    Klicken Sie in der E-Mail auf die blaue Schaltfläche für Ihren Browser – Für Microsoft Edge hinzufügen oder Für Google Chrome hinzufügen. Klicken Sie im Store auf «Abrufen» bzw. «Hinzufügen» und bestätigen Sie mit «Erweiterung hinzufügen».

    Edge erkennen Sie am blau-grünen Wellen-Symbol, Chrome am rot-gelb-grünen Kreis.

  5. 5
    Symbol anheften

    Klicken Sie oben rechts auf das Puzzle-Symbol und auf die Stecknadel neben «DEXXUS WEB Shield».

  6. 6
    Lizenz einlesen

    Öffnen Sie chatgpt.com, klicken Sie auf das blaue DX-Symbol, dann auf Lizenz erhalten?, und ziehen Sie die Lizenzdatei vom Desktop in das Feld.

Installation abgeschlossen. Gratulation – Sie haben WEB Shield erfolgreich installiert. WEB Shield zeigt oben «Gratis-Test bis …» bzw. «Abo aktiv bis …».
Gratulation, Sie haben sich für Shield, den KI-Schutz, entschieden – das ist clever.
Bei Fragen wenden Sie sich bitte an den Support von DEXXUS: info@dexxus.ch
Version 3 · Windows

PC Shield

Programm für Windows 10 und 11. Gilt für DEXXUS Shield sowie die Varianten bexio, Abacus, SelectLine und Praxis.

AbsenderDEXXUS
BetreffIhre DEXXUS-Lizenz L-2026-0123
EnthältLink «PC Shield herunterladen» · Anhang Lizenzdatei «L-2026-0123.dxlic»
Am PC
  1. 1
    E-Mail am PC öffnen

    Öffnen Sie die E-Mail von DEXXUS in Ihrem E-Mail-Programm am PC.

  2. 2
    Lizenzdatei speichern

    Klicken Sie mit der rechten Maustaste auf den Anhang L-2026-0123.dxlic, wählen Sie «Speichern unter» und speichern Sie die Datei auf dem Desktop.

  3. 3
    Programm herunterladen

    Klicken Sie in der E-Mail auf den Link PC Shield herunterladen. Die ZIP-Datei wird im Ordner «Downloads» gespeichert.

  4. 4
    ZIP-Datei entpacken

    Öffnen Sie den Ordner «Downloads». Klicken Sie mit der rechten Maustaste auf die ZIP-Datei, wählen Sie «Alle extrahieren» und klicken Sie auf «Extrahieren».

  5. 5
    Installation starten

    Doppelklicken Sie im entpackten Ordner auf INSTALLIEREN.bat. Die Installation läuft automatisch (Internetverbindung erforderlich).

    Zeigt Windows «Der Computer wurde durch Windows geschützt», klicken Sie auf «Weitere Informationen» und dann auf «Trotzdem ausführen».

  6. 6
    Programm starten

    Doppelklicken Sie auf das neue Symbol auf dem Desktop.

  7. 7
    Lizenz einlesen

    Klicken Sie auf «Einstellungen», öffnen Sie den Reiter «Lizenz», klicken Sie auf Lizenzdatei einlesen und wählen Sie die Datei auf dem Desktop.

  8. 8
    Neu starten

    Schliessen Sie das Programm und starten Sie es erneut.

Installation abgeschlossen. Gratulation – Sie haben PC Shield erfolgreich installiert. Das Programm meldet «Auf diesem PC freigeschaltet».
Gratulation, Sie haben sich für Shield, den KI-Schutz, entschieden – das ist clever.
Bei Fragen wenden Sie sich bitte an den Support von DEXXUS: info@dexxus.ch
